# BSIMM Security Assessment

**Author: Francisca Tupkeyi**

A software security assessment project using the Building Security In Maturity Model (BSIMM) to identify gaps and recommend improvements across a software security initiative.

[View the full assessment (PDF)](reports/BSIMM-Security-Assessment.pdf)

## Project context

This educational case study examines Full Sail University as presented in the project scenario. The current-state statements and recommendations reflect that scenario; they are not findings from an independent audit of the university's live systems.

## Assessment approach

The report maps selected BSIMM activities to three elements: current state, identified gap, and recommended improvement.

| Domain | Areas covered |
| --- | --- |
| Governance | Strategy and metrics, compliance and policy, training |
| Intelligence | Attack models, security features and design, standards and requirements |
| SSDLC Touchpoints | Architecture analysis, code review, security testing |
| Deployment | Penetration testing, software environment, configuration and vulnerability management |

## Key recommendations

- Document a secure software development lifecycle and establish a security champions program.
- Strengthen privacy policies, personal information inventories, and security training.
- Integrate architecture reviews, automated code analysis, and security testing into development.
- Apply security baselines to development environments.
- Involve developers in incident response and define an emergency patching process.
- Use operational findings to improve standards, training, and testing.

## Skills demonstrated

Software security gap analysis, BSIMM activity mapping, security governance, privacy and compliance analysis, secure development planning, and remediation recommendations.
